# Halo Run Enhancer

A modern GUI tool for enhancing Halo gameplay runs with tied modifier pairs.

## Features

* **Modern GUI** built with PySide6
* **Auto-loads** `halo.json` from the application folder
* **Mission-aware**: Only shows enemies from the current mission
* **Exclusive weapon selection**: Each player gets unique weapons
* **3 pairs** of tied modifiers generated per player
* **Reroll individual effects** for fine-tuning
* **Wildcard system**: 10% chance for friend modifiers
* **Complete save data** with tag and field information
* **Turn-based selection**: Player 1 chooses, then Player 2
