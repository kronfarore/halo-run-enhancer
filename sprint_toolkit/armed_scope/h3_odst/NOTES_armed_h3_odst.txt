== 4. ANIMATION: THE ENGINE RULE (H3EK sapien.exe; MCC halo3.dll and ODST not disassembled)
unit_can_use_weapon 0x96e170 calls 0x9a9e00(unit, mode, weap Class +0x3DC, weap Name +0x3E0): looks up action 'idle'.
 mode = 'current' (or seat mode); unset falls to 'combat' (0x4be2f2); if the flag is set, retry in 'combat'.
 0x4be240: class replaced by graph WEAPON LIST (jmad +0x8C, bsearch, 8 bytes) entry for the weapon NAME, unless class = dual.
 0x5d0db0 / 0x7442c0: tries all 8 combinations of mode|any, class|any, type|any, then action.
 So a weapon is REFUSED only if no combination holds 'idle'. Refused = no weapon on spawn.
gate.py replays this on the dumped graphs (combat row). Stock proof that the class-any fallback works: floodcombat_brute (graph has no
rifle class) carries spike_rifle, BR, shotgun, AR on Bungie's 050 locations.
Stock proof mode rows do not gate: Brute patrol has no idle row for any weapon class, yet stock Brutes patrol armed.
Combat row, weapons refused (H3; ODST same on sc100 and l200):

        crouch/patrol lack them (refused rows there: 17 of 29).

SAW Name is 'ar', so it takes every AR animation row. H3 raw sids: missile 0x310, support 0x311, rifle 0x312, pistol 0x313, sword 0x314; ODST +5.
